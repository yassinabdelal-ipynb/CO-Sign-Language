# Demonstrations

`events.jsonl` is a deterministic generated stream covering 26 letters and three phrases. Each row has monotonic seconds, a class label and confidence. Run it with `realtime_detection.py --events demos/events.jsonl`.

No testing videos are included yet. Add links below only after recording, obtaining any required permission and checking visible names/screens. Prefer a GitHub release asset or an authorized video link to committing large videos; common recording formats are Git-ignored.
